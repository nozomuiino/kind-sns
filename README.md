# やさしいTL

X（旧Twitter）のタイムラインで、注目を集めるために怒りや不安をあおる投稿や、人を攻撃する投稿を AI で判定して、1行に畳む Chrome 拡張です。

判定には TypeSafe の [jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) を使います。投稿1件につき1回の問い合わせで、6つの分類それぞれに「当てはまる確率（0〜1）」を出します。しきい値を超えた投稿は次のように畳まれ、「表示する」で中身を開けます。

```
🌿 やさしくないかもしれない投稿をたたみました                 表示する
不安あおり 0.96 / 属性への攻撃 0.90 / 炎上狙い 0.85
```

## 必要なもの

- パソコンの Google Chrome（または Chromium 系ブラウザ）。スマホの X アプリでは動きません。
- TypeSafe の API キー。[console.typesafe.ai](https://console.typesafe.ai/) で取得します（2026年9月時点ではアーリーアクセスです）。

## インストール

Chrome ウェブストアには出していないので、フォルダから読み込みます。

1. このリポジトリをダウンロードする。
   - git を使う場合：`git clone https://github.com/nozomuiino/kind-sns.git`
   - 使わない場合：GitHub の「Code」→「Download ZIP」でダウンロードして展開する
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、リポジトリの中の **`extension` フォルダ**を選ぶ。リポジトリのいちばん上のフォルダではありません。
4. ツールバーの拡張機能アイコン（パズルのピース）から「やさしいTL (jev)」を押すと、設定画面が開く。
5. API キーを貼り付けて「接続テスト」を押す。`OK (jev-…, …ms)` と分類ごとのスコアが出れば接続できています。
6. 「保存」を押し、x.com を開く（開いていたら再読み込みする）。

## 設定

設定画面で次のことができます。

- **分類ごとのオン・オフとしきい値**：しきい値（0〜1）を下げるほど畳まれやすくなります。最初はすべて 0.5 です。
- **畳み方**
  - 明示する（既定）：理由とスコアつきの1行を残す
  - 控えめ：細い点線だけを残す。ホバーで理由が出る
  - 完全に非表示：何も残さない。隠した件数はツールバーのバッジに出る
- **判定待ちの表示**：判定が終わるまで投稿を薄く表示するかどうか

## 分類

| 分類 | 内容 |
|---|---|
| 炎上狙い | 怒りや対立をあおって反応を集める |
| 不安あおり | 「手遅れ」「崩壊」などで恐怖をあおる、根拠のない断定 |
| 見下し・嘲笑 | 人を笑いものにする、見下す |
| 名指しの攻撃 | 特定の人へのリプライで叩く、晒す |
| 属性への攻撃 | 性別・国籍・世代などでひとくくりにして攻撃する |
| マウント・嫌味 | 直接の暴言ではないけれど、読むとしんどくなる |

分類の中身（jev への質問文やタグ名）は [`extension/categories.js`](extension/categories.js) にまとまっています。書き換えたら `chrome://extensions` で「やさしいTL (jev)」の再読み込みボタン（↻）を押し、X のタブを再読み込みしてください。質問を変えると、前の判定結果は使われなくなります。

## データの扱い

- **jev に送るもの**：画面に表示された投稿の本文だけです。投稿者の名前や ID は送りません。
- **API キー**：この拡張の中（`chrome.storage.local`）にだけ保存します。
- **判定結果のキャッシュ**：同じ投稿を何度も問い合わせないよう、ブラウザの中に最大 3000 件まで保存します。保存するのは本文のハッシュ値とスコアだけで、本文そのものは保存しません。
- X 上で投稿・いいね・フォローなどの操作は一切しません。表示を変えるだけです。

TypeSafe に送った本文がどう扱われるかは、TypeSafe の利用規約を確認してください。

## ファイル構成

```
extension/
  manifest.json   拡張の定義（Manifest V3）
  categories.js   分類の定義（ここを書き換えて分類を変える）
  content.js      x.com 上で投稿を拾い、判定結果に応じて畳む
  background.js   jev への問い合わせとキャッシュ
  ui.js, ui.css   畳んだ行の見た目とアニメーション
  settings.js     設定の読み書き
  options.html, options.js   設定画面
```

ビルドは不要です。

## AI エージェント向けのセットアップ手順

ユーザーから「このリポジトリの拡張機能を入れて」と頼まれた場合は、次の順に進めてください。

1. リポジトリを clone する：`git clone https://github.com/nozomuiino/kind-sns.git`
2. 読み込むフォルダの絶対パス（`<clone先>/kind-sns/extension`）をユーザーに伝える。
3. `chrome://extensions` での読み込みは、ブラウザのセキュリティ上、ユーザー本人が操作する必要があります。上の「インストール」の手順 2〜6 を案内してください。
4. API キーはユーザー本人に設定画面へ貼り付けてもらってください。チャットに貼らせたり、ファイルに書いたりしないでください。
5. 動作確認：設定画面の「接続テスト」で `OK` と出ること、x.com を再読み込みすると判定待ちの投稿が一瞬薄く表示されることを確かめる。

うまく動かないときの確認点：

- 拡張が入っているのが、X にログインしている Chrome のプロフィールと同じか
- `chrome://extensions` で拡張がオンになっているか、赤い「エラー」が出ていないか
- 「詳細」→「サイトへのアクセス」が「クリック時」になっていたら、「すべてのサイト」に変える
- 接続テストで `HTTP 401` や `HTTP 403` が出る場合は、API キーが間違っているか、有効になっていない
